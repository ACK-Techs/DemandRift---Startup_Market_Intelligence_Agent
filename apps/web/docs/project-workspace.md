# FE-04 proje çalışma alanı

`/projects` kanonik Session içindeki owner bağlamıyla `GET /api/v1/projects` ve `POST /api/v1/projects` tüketir; `/projects/{projectId}` kanonik `GET /api/v1/projects/{projectId}` detayını gösterir. Proje UUID'sini backend üretir. Cookie aynı origin `/api/backend` üzerinden gönderilir; create CSRF değeri yalnız doğrulanmış oturumdan alınır. Serbest upstream URL veya model credential bu modüllerin girdisi değildir.

`Project`, `ProjectPage` ve `ProjectCreate` aynı üretilmiş kanonik wire schema üzerinden doğrulanır. Liste nested owner UUID'lerini, detay owner ve istenen project UUID'sini denetler. `200` list/detail ve `201` create makbuzu ayrı beklenir. Liste 25 kayıtlık sayfadır; opaque server cursor aynen aktarılır ve bir sonraki sayfa mevcut sayfayı değiştirir. Görünen kayıt sayısı yalnız okunan sayfanın uzunluğudur; toplam proje/araştırma sayısı türetilmez. Yinelenen UUID, archived liste kaydı, boş veya aynı cursor, sınır dışı kayıt sayısı ve beklenmeyen page limit sözleşme hatasıdır. Detayda archived proje gerçek kaydı olarak ayrıca gösterilebilir.

Owner bağlı store yalnız bellektedir. `ProjectResources` tek bir sınırlı store'u `SessionProvider` içindeki owner Fragment'ın üstünde tutar; `useProjectStore` component yaşam döngüsü artık oturumu boşaltmaz. Store en çok bir liste sayfası, bir detay ve bir pending/unknown create yakalaması tutar. Aynı owner içindeki component remount veya sayfa gezinmesi yeni bir create işlemi üretmez. Logout/expiry, owner/CSRF değişimi, doğrulanmış401, broadcast veya provider unmount private kayıtları, yakalamayı ve istekleri temizler; geç gelen önceki owner yanıtı generation kontrolüyle reddedilir. Detay URL'sindeki UUID değişince eski proje gösterilmez; yeni scoped GET beklenir. Authenticated session olmadığı sürece proje kontrolleri ve kayıtlar görünmez. Protected401 bütün proje cache'ini kaldırır. Ayrıca doğrulanmış kanonik ApiError ile gelen401, isteğin başında kopyalanmış primitive owner UUID ve csrf_token üzerinden global account store'un `invalidateSession` API'sine gider. Yalnız halen aynı oturum kimliğiyle eşleşiyorsa cached Session/topbar ve private bileşenler temizlenir. Kullanıcı açık session kontrolü veya manuel giriş yapabilir; bu temizlik otomatik GET/POST/retry başlatmaz. 403, 404, HTML/bozuk ApiError401 veya network/timeout/contract belirsizliği global logout anlamına gelmez.

Pasif focus/visibility GET önce mevcut SessionStore private-resource API'siyle store'u suspend eder. Public snapshot owner, kayıt, DTO veya yakalanan create input içermez; proje DOM'u eski account görünürlüğüyle açık tutulmaz. Pending GET'ler abort edilir ve kullanıcı açık yeni okuma yapabilir. Gönderilmiş olabilecek pending POST abort edilince unknown olur; abone bildirimi sırasında henüz client'a verilmemiş bir işlem gönderilmez. Hiçbir suspend/bind/timer otomatik POST veya create retry yapmaz. Store aynı doğrulanmış primitive owner+CSRF ve henüz sona ermemiş continuity altında eski unknown/confirmed state'i geri verir. Başarısız, bozuk veya network sessionGET store'u private olarak suspended tutar; eski absolute expiry geçerse yakalama temizlenir. SessionStore public API'si değişmez.

Unknown durum matching GET ile doğrulandıktan sonra da yeni POST'u kilitler; yalnız “Check saved projects” ile açık liste okuma ve daha sonra açık “Continue after reviewing list” niyeti vardır. Fragment remount sırasında uncontrolled input metni yeniden kurulsa bile boş kutu yeni POST izni değildir; yakalama ve unknown kilidi bellekte kalır. Original isim, primitive CSRF ve private yanıt hiçbir localStorage/sessionStorage, URL, log veya analitiğe yazılmaz. Project endpoint idempotency/receipt sözleşmesi kazanmaz; research/brief opaque locator başka kapsamdır. Broadcast pending auth reconciliation sırasında da project store'u hemen temizler. Başarısız passiveGET global CAS lineage'ını kaybetmişse geç gelen matching canonical private401 suspended yerel yakalamayı da siler; yeni owner/token korunur.

Her list/detail/create isteği kimlik değerlerini await'ten ve loading bildiriminin aboneleri çalıştırmasından önce yakalar; sonuç geldiğinde kimliği mevcut mutable Session'dan türetmez. Kanonik401 bildirimi stale project generation veya disposed store sonucu düşürülmeden önce yapılır: GET account refresh sırasında eski kimlik halen tutuluyorsa bu gerçek reddi Session CAS ile karşılaştırmak gerekir. Geç GET account makbuzu ardından oturumu geri getiremez. CSRF'si dönen aynı owner, yeni owner veya yeni login/register/logout işlemi varsa CAS eski401 bildiriminin onu temizlemesini veya iptal etmesini reddeder. Proje cache'i bu sırada eski yanıtla yeniden doldurulmaz. Session wire sözleşmesine yeni kimlik alanı eklenmez.

Project name 1–200 Unicode karakter ve nonblank kanonik girdi kontrolünden geçer; trim/case değişikliği olmadan gönderilir. Pending store kilidi ikinci create POST'u engeller; başarılı submit formu temizler. `201` owner/name/archive makbuzu doğrulanmadan başarı bağlantısı çıkmaz. Known create kaydı ayrı receipt'tir; server listesine kayıt eklenmiş gibi bir sayfa üretilmez. User listeyi GET ile yeniler veya dönen güvenilir UUID detayına gider.

Network/timeout/5xx veya bozuk successful receipt sonrası create sonucu `unknown` olur. Aynı view'de yeni POST durur; “Check saved projects” yalnız açık GET yapar. Listede aynı isimli kayıt bulunması önceki POST sonucunu benzersiz biçimde belirlemez; create receipt veya confirmed UUID uydurulmaz. Kullanıcı kayıtları okuduktan sonra “Continue after reviewing list” açık ayrı-create niyetiyle formu açabilir. Önceki sonucu belirsiz olan POST otomatik yeniden gönderilmez. Backend create route bu dilimde idempotency key desteği sağlamaz; tarayıcı full reload/provider kaybı veya yeni session ardından eski bilinmeyen POST'u kalıcı biçimde uzlaştırma parent integration'da ayrıca değerlendirilir. Bu store backend transaction/idempotency yetkisinin yerine geçmez.

Loading, boş sayfa, auth/expiry, permission, not_found, unavailable, validation, rate_limit, contract ve unknown ayrı görünür. Pozitif kanonik Retry-After süre boyunca yeni isteği durdurur; sıfır manuel yeniden denemeyi açık bırakır, otomatik retry yoktur. Suspend eski timer generation'ını iptal eder; matching bind orijinal absolute retryUntil üzerinden kalan zamanı yeniden hesaplar ve aynı deadline'a yeni timer kurar. GET doğrulaması süreyi sıfırlamaz veya uzatmaz; hidden iken dolmuş süre manual GET'i açar, unknown POST kilidini açmaz. Alan hatası input ile `aria-describedby` üzerinden bağlıdır. Scoped layout ilk keyboard linkiyle proje içeriğine atlar; semantic form, alert/status ve minimum44px kontroller korunur. Mevcut DemandRift tasarımı yeniden tasarlanmaz.

Research history API henüz bu view'e bağlanmadığından detay “Research history unavailable” gösterir. Project yaratmak research run başlatmaz; fake araştırma sayısı, ilerleme veya karar sonucu yoktur. Backend brief/research contract teslimi geldiğinde ayrı tüketici işi bu alana bağlanacaktır.

`npm run test:projects` fixture HTTP üzerinden scope/receipt/Unicode/pending/unknown/pagination/error/owner değişimi/deadline kontrolleridir. Typecheck ve lint geliştirme kapılarıdır. Bounded Playwright desktop/mobile/keyboard ve list/create/detail/logout/unknown/error akışlarını açıkça mocked API yanıtlarıyla test eder; gerçek Hetzner session/proxy/cookie/CORS kanıtı değildir. Parent FE-04 gerçek uçtan uca kabulü ve final87 zorunlu senaryolar açık kalır. Frontend deployment, key erişimi ve sağlayıcı çağrısı yapılmaz.
