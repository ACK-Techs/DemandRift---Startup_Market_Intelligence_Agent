# FE-02 API sözleşme tüketimi

`lib/api/wire.ts` doğrudan Python üreticisinin `packages/contracts/src/generated.ts` tiplerini ve `schema/wire.schema.json` serialization schema'sını tüketir. Ajv8.20.0 draft2020 ve ajv-formats3.0.1 UUID/aware datetime doğrular. [Ajv şema belgesi](https://ajv.js.org/json-schema.html) ve [format belgesi](https://ajv.js.org/guide/formats.html) kullanılan doğrulayıcıyı tarif eder. Runtime model adı generated `schema.models` own-property whitelistinden seçilir; prototype/unknown model adları reddedilir. Coercion/default/removeAdditional kapalıdır: gelen ham JSON string başarıda ve sözleşme hatasında aynen korunur; bilinmeyen alan sessizce atılmaz. Büyük integer veya numeric money kabul edilmez. Backend'in semantic model validator'ları, quote doğruluğu ve karar yeterliliği backend kabul kapılarıdır; frontend JSON shape kontrolü bunların geçtiğini iddia etmez.

Client yalnız local frontend'in aynı origin `/api/backend/api/v1/...` proxy path'ini kullanır. Serbest upstream URL, path traversal ve redirect yoktur. GET'ler cache edilmez; kimlikli response caller'ın beklediği owner/project/research scope'una göre generated schema üzerinde gerçek DTO kimlik alanlarıyla nested kayıtlar dahil denetlenir. Serbest kaynak metadata/provenance dictionary anahtarları tenant kimliği sayılmaz. Oturum cookie'si same-origin, mutation CSRF ve idempotency header'ları explicit verilir. Model credential bu modüllerin girdisi değildir. Güvenli local proxy ve gerçek auth bağlantısı FE-03/OP-03 ayrı teslimidir; bu client dosyaları tek başına canlı backend bağlantısı anlamına gelmez.

Mutation otomatik retry edilmez. Outbound JSON serialization nonfinite/unsafe integer sayıları (nested veya toJSON sonucu dahil) gönderilmeden reddeder; null'a sessiz dönüşüm yoktur. Boxed Number object desteklenmez; primitive JSON number gerekir (cross-realm/toJSON sonuçları dahil). Timeout/network/abort veya server5xx sonucunda `operationState=unknown` döner; kullanıcı aynı idempotency key ile sunucudaki kaydı okuyup sonucunu çözmelidir. Pre-aborted/yerel validation `not_sent` olur. HTTP4xx `rejected`; read abort `cancelled` olabilir. Yanıt UTF-8 JSON olmalı ve2MiB byte sınırını aşmamalıdır; büyük sonuçlar backend pagination/export üzerinden alınır. Tamamlanmış UTF-8 ve2MiB sınırı içindeki response raw olarak korunur; sınırı aşan veya undecodable byte yanıtında raw yoktur. Raw response hata log'una veya varsayılan UI metnine yazılmaz; canonical error/request_id/retry_after_seconds gerektiğinde caller tarafından okunabilir.

Ortak mapping12 run ve12 source durumunu ve4 karar türünü ayrı tutar. `completed` yalnız işlem tamamlanmasını söyler; yeterlilik, confidence veya karar sonucu üretmez. `no_results`, unavailable, policy, challenge, rate_limit ve budget ayrı anlam taşır. Bilinmeyen durum terminal sayılmaz. Bütün ekran bağlantıları bu mapping'i kullanacak; aktif kapsam üç fazdır.

`npm run test:contracts` gerçek Python producer fixture'larını ve HTTP/scope/decimal/version/unknown/timeout/byte-limit davranışlarını test eder. `typecheck`, `lint`, `build` geliştirme kapılarıdır; gerçek Hetzner/browser final kabulü ayrıca zorunludur. Gemini/live source/final87 bu bounded FE-02 teslimiyle tamamlanmaz.

Kabul edilen preparation genişlemesiyle katalog 39 modeldir. `ResearchCreate`, `HumanBriefPatch`, `BriefReference`, `ResearchPreparation`, `ResearchPreparationPage`, `BriefPage` ve `PreparationMutationReceipt` aynı generated Python schema ve TypeScript producer'dan güçlü tipli tüketilir. `WireCatalogParity` typecheck sırasında frontend tip haritasının generated katalogla birebir kapsamasını zorunlu kılar. Eski 32-model testinin fiili failure kanıtı korunur; yeni kontrol kabul edilen katalog adlarını ve her modelin derlenmesini doğrular. İkinci schema producer veya model default'u eklenmez.

Preparation için JSON Schema'nın taşıyamadığı belirli Python kuralları ayrıca denetlenir: create dil listesi tekildir; sparse `HumanBriefPatch` version yanında en az bir gerçekten gönderilmiş edit taşır; gönderilmiş language/modifier listeleri tekildir, constraint Name anahtarları nonblank olmalıdır. Omitted alanlar eklenmez, açık null edit aynen korunur; boş constraints/modifiers veya açık false Python'un izin verdiği edit olarak geçerlidir. Python strict expected version alanındaki `1.0` veya `1e0` JSON token'ı integer değildir. Bu alan native JSON parse source bağlamıyla kontrol edilir; source desteği bulunmayan runtime bu patch'i sözleşme hatası olarak reddeder. Integer/string/boolean dönüşümü yapılmaz; diğer mevcut modellerin JSON parsing davranışı değişmez.

R1 bağımsız incelemede bulunan altı Unicode uyuşmazlığını kapatır. Pydantic'in Rust `\\S` deseni Unicode White_Space kümesini kullanır: U+0085 NEL whitespace, U+FEFF BOM nonwhitespace'tir; ECMA `\\S` bunun tersini uygular. Yalnız yedi yeni preparation model root'u için ayrı Ajv instance'ının desteklenen RegExp engine'i, değişmeyen generated desenleri producer'ın bu sabit Unicode kümesiyle yorumlar. Böylece BOM schema kontrolünden önce yanlışlıkla reddedilmez; NEL yanlışlıkla kabul edilmez. Aynı matcher nested Name dictionary anahtarlarında ve scope traversal'da kullanılır. Kanonik JSON Schema/producer dosyası, raw string ve parse edilmiş değer değişmez; eski 32 modelin varsayılan regex yorumlaması korunur. Rust'ın nonwhitespace saydığı U+001C–1F kontrol karakterleri, Python `str.strip()` bunları boş saysa da kanonik model kontrolünde kabul edilir; downstream backend işlem kuralları ayrı kalır. Uzunluk kontrolleri UTF-16 code unit yerine Unicode code point sayısını kullanır. İlk author PASS ve bağımsız review/verify FAIL kanıtları ayrı korunur; yeni diferansiyel kabul bunların üzerine yazılmaz.

Genişletilmiş Python diferansiyelinde bulunan escaped lone surrogate girdileri de yalnız yeni yedi modelin scalar intake kontrolünde reddedilir; geçerli high/low çiftleri astral karakter olarak kabul edilir. Bu kontrol değerleri veya dictionary key'lerini dönüştürmez. İlk R1 Unicode boundary failure çıktısı da düzeltme sonrası sonuçtan ayrı korunur.

`IdeaBrief`, `BriefPage` ve recovery receipt içindeki non-null `versions.brief`, explicit `brief_version` ile eşleşmelidir; Python'un izin verdiği null recorded version korunur. Receipt top-level owner/project/research/brief/version değerleri nested immutable brief ile birebir aynı olmalıdır. Caller'ın verdiği owner/project/research scope'u nested sayfalara ve receipt brief'e de uygulanır; serbest provenance dictionary anahtarları tenant ID sayılmaz. Op/request_key ve istenen exact historical brief/version gibi seçime bağlı kontroller bunları isteyen store'un sorumluluğudur. Bu sınırlı frontend denetimi diğer tüm backend semantic validator'ları, kaynak/alıntı doğruluğu veya karar yeterliliğinin kabulü anlamına gelmez. Preparation ekranı, mutation/recovery kullanıcı akışı ve gerçek Hetzner bağlantısı ayrı teslimlerdir.


FE-03 auth tüketimi için `client.logout(csrfToken)` yalnız kanonik `POST /api/v1/auth/logout` boş `204` yanıtını başarı sayar; JSON endpoint'lerinin boş yanıtı aynı şekilde sözleşme hatası kalır. CSRF token primitive string olarak kanonik 64 küçük hexadecimal karakter olmalı; boxed String, array ve toString coercion gönderilmeden reddedilir; yanlış token yerelde `not_sent` olur. Credentials, redirect, timeout, byte sınırı ve mutation için bilinmeyen sonuç davranışı ortak transport üzerinden korunur. `200`/`205` veya beklenmeyen yanıt logout başarısı üretmez; timeout/network/5xx otomatik retry edilmez. Bu istemci davranışı canlı backend ya da oturum arayüzü kabulünü tek başına tamamlamaz.
