# Operations application role bootstrap

`python -m app.runtime_bootstrap` yalnız güvenilir operations/migrator container'ında çalışır. API/worker bu modülü import etmez ve admin credential almaz. Admin `DATABASE_URL_FILE`; application `DEMANDRIFT_APPLICATION_DATABASE_FILE`; uygulama rolü `DATABASE_APP_ROLE` (default `demandrift_app`) ile sabitlenir. İki private DSN credential dışında aynı tek PostgreSQL database/host/options seçmelidir. Yeni runtime secret üretiminde güçlü rastgele parola kullanılır; bootstrap karakter/uzunluk sınırını ayrıca uygular.

DSN query politikası açık allowlist'tir: `sslmode` tek değer olarak `disable`, `allow`, `prefer`, `require`, `verify-ca` veya `verify-full` olabilir. Native Unix socket bağlantısında authority host/port boş, query `host` tek absolute ASCII directory ve `port` 1–65535 arasında tek sayı olmalıdır. Authority bağlantısı tek hostname/IP seçer; query host/port ile değiştirilemez ve eksik authority port açıkça 5432 olur. Database adı sınırlı ASCII identifier'dır; URI/conninfo biçimi kabul edilmez. Query `user`, `password`, `username`, `dbname`, `database`, `service`, `servicefile`, `passfile`, `hostaddr`, arbitrary `options` ve diğer tüm anahtarlar reddedilir. Aynı değer tekrar edilmiş olsa bile çok değerli query parametresi kabul edilmez. Ham DSN query çiftleri URL normalizasyonundan önce kontrol edilir; boş değer, eksik değer veya tekrar URL parser tarafından düşürülüp gizlenemez. DSN uzunluğu private FILE sınırıyla aynı 4096 karakteri geçemez. Böylece libpq query merge işlemi URL'deki uygulama rolü/parolasını değiştiremez; invalid veya forged config, Database oluşturulmadan ve SQL çalışmadan önce güvenli hata verir. Aynı query politikası admin DSN'ye de uygulanır.

Application FILE ayrı, kısa ömürlü child'ın private stdout pipe'ında mevcut no-follow/file-mode/UID/size/ASCII loader ile okunur. Parent environment değişmez; child'a Gemini/broker credential ayarları verilmez. Değer CLI argument, dosya kanıtı, log veya exception metni değildir. Invalid child/FILE/config/native SQL güvenli generic failure ve exit1 verir.

Operations migrator aynı private yükleme ve strict DSN sınırını `configured_bootstrap_config() -> BootstrapConfig` üzerinden kullanabilir. Bu fonksiyon SQL çalıştırmaz, environment değiştirmez ve DSN'leri repr'de gizler. `configured_bootstrap()` bu config'i yükleyip rol bootstrap'ini çağırır; mevcut `created`/`existing` sonucu korunur. API/worker bu operations arayüzünü kullanmaz.

Bootstrap transaction doğru DSN current/session superuser hesabını doğrular; uygulama rolü için transaction advisory lock alır. Yeni rol login/no-superuser/no-createdb/no-createrole/no-bypassrls/no-replication/no-inherit ve connection limit20 ile oluşturulur. Password bound parameter ile private transaction GUC'de tutulur; utility DDL server içinde identifier/literal quoting yapar. Standard PostgreSQL statement/duration/sample/parameter/error logging session kapsamında kapalıdır; audit extension veya dış SQL proxy log güvenliği burada kanıtlanmaz.

Var olan rol login, admin flag, role membership ve herhangi object ownership açısından denetlenir. SCRAM-SHA-256 stored/server key, beklenen private application password ile constant-time karşılaştırılır. Yanlış password/MD5/unsafe rol failclosed'dur; rol/parola onarılmaz veya resetlenmez. Başarı `created`/`existing` değeridir; transaction commit'ten önce başarılı sonuç dışarı dönmez.

Yeni boş database'de sıra: restricted role bootstrap → admin one-shot Alembic head008 → application role/head native kontrolü → API/worker. Var olan database'ye başka bir rol eklemek eski migration grant'larını yeniden çalıştırmaz; migration/role grant uyumu ayrıca gate'dir. Mevcut Compose operations profile bu bootstrap/application FILE bağlantısını henüz içermez; kurulum ve trusted deploy helper ayrı kabul checkpoint'i gerektirir. Native disposable downgrade yalnız yeni test database'inde kullanılır; production rollback davranışı değildir. Unix trust bağlantısı SCRAM ağ authentication kanıtı değildir; gerçek Hetzner native SCRAM/login/UID/mount/log/recovery ayrıca kabul edilir.
