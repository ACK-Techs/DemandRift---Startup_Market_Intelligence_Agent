# BE-06: izinli kaynak çıkışı temeli

`app.source_egress` yalnız kaynak kimliği, izinli path ve typed query çiftleriyle tek HTTPS GET hazırlayan backend katmanıdır. Public `fetch_source` URL, profile, grant, policy, header, cookie, credential veya transport kabul etmez. API route, worker handler veya acquisition pipeline bu teslimde bağlanmaz; frontend sözleşmeleri değişmez.

Production builder paketlenmiş registry'yi raw JSON/digest/type kontrollerinden yeniden geçirir. Identity ve profile için gerçek boolean `runtime_enabled=True`, profile için current permission `approved` ve aynı source kimliğine ait güncel server grant birlikte gerekir. Mevcut636 identity/15 profile kapalıdır; current permission `unknown` kalır. LiteralFalse şeması değişmez; `model_copy` ile yükseltilmiş kayıt yeniden parse edilirken reddedilir. Tarihsel F03 endpoint/health/eligibility bilgisi izin yerine geçmez.

`_server_permission` varsayılan olarak hiçbir grant döndürmez. Sunucuda gözden geçirilmiş izin deposu tüketicisi daha sonraki entegrasyondur; bu dosyada grant kaydı yükleme veya dışarıdan grant kurma API'si yoktur. Gerçek producer bağlanmadan canlı kaynaklar açılamaz. Immutable `ServerGrant`, review kimliği/hash'i, açık permission ve robots sonucu, UTC başlangıç/bitiş zamanı, tam origin/path/query kuralları, MIME ve limitler taşır. Bunlar sunucunun güvenilen inceleme kayıtlarıdır; bir istemcinin bu alanları yazması izin oluşturmaz. Grant, registry enable ve permission koşullarını kaldıramaz. Testlerde yalnız açıkça isimlendirilmiş gelecekteki server catalog/permission fixture'ları başarılı transport kontrolü için kullanılır; production registry aynı kalır.

Origin yalnız canonical ASCII HTTPS hostname ve varsayılan/explicit443 portudur. Credential, fragment, path/query içeren origin, farklı port, localhost/local suffix, IP literal, encoded/Unicode/punycode hostname reddedilir. Path tam onaylı string ile eşleşir; dot segment, percent encoding, double slash, backslash veya query/fragment içeren path kabul edilmez. Query tam schema'daki benzersiz string çiftlerinden oluşur; UTF8 byte sınırı, gerektiğinde sabit allowed values ve credential key yasağı vardır. Query değerleri URL encoding ile literal veri olur. Kullanıcı header veya SNI belirleyemez.

DNS işi standart resolver ile ayrı private Python interpreter'de çalışır. Host dışında request/query/credential child argümanına veya environment'ına verilmez; shell çalıştırılmaz. Child en fazla16 candidate ve2048 byte çıktıya izin verir. Timeout child'ı öldürür ve bekler; resolver thread geride bırakılmaz. Bütün DNS adayları incelenir: private, loopback, link-local, unspecified, multicast, reserved/shared/documentation adresleri kapalıdır. Bu temel IPv4 ile sınırlıdır; native/mapped/scoped IPv6 veya mixed A/AAAA sonucu da reddedilir. Adres filtreleyerek uygun aday seçme veya hata sonrası başka adrese geçme yapılmaz. Bu IPv6 desteği iddiası değildir.

Doğrulanmış public IPv4 kümesinden deterministic tek aday, httpcore `NetworkBackend.connect_tcp` sınırında sayısal adrese sabitlenir. OS connect yalnız AF_INET socket ve numeric tuple kullanır; ikinci hostname DNS çözümü yoktur. Request origin/Host ve TLS server hostname özgün onaylı hostname olarak kalır. TLS context, hostname check ve CERT_REQUIRED ile explicit certifi CA bundle kullanır; ambient proxy veya CA environment ayarı transportu değiştirmez. Tek connection/pool, retries0, keepalive0, HTTP1 ve proxyNone kullanılır. Cookie jar, authorization, model key, proxy authorization, redirect following, retry ve fallback yoktur.

Tek monotonic deadline policy hazırlığından DNS, connect, TLS, write, response headers ve bütün partial body okumalarına kadar taşınır. Grant expiry bu deadline'ı daha da kısaltır. DNS/connect/read için ayrıca üst sınırlar vardır; her socket write/read kalan süreye göre sınırlandırılır. İlerleyen partial sonuç yeni süre başlatmaz. Owned stream/pool her sonuçta kapatılır; hatalar yalnız `Source acquisition unavailable` üretir. Bu hata kaynak yokluğu/izin/transport sorunudur; başarılı boş arama sonucu değildir.

Yalnız HTTP200 ve grant'ın izinli MIME'ı kabul edilir; optional charset yalnız UTF8 olabilir. Duplicate kritik header, conflicting framing, redirect/error/no-content ve nonidentity Content-Encoding reddedilir. Ham `Content-Type`, `Content-Encoding`, `Content-Length` ve `Transfer-Encoding` occurrence'ları, HTTP parser normalizasyonundan önce case-insensitive olarak kontrol edilir. Aynı değerli iki Content-Length satırı da `2, 2` gibi listeler de reddedilir; parser'ın bunları tek değere çevirmesi izin sağlamaz. Başlık syntax'ı CRLF ve token header name gerektirir; obs-fold, bare LF ve colon öncesi whitespace kapalıdır.

Tek pinned stream, ham başlıklar bitip doğrulanana kadar aynı okunan byte'ları sınırlı bir buffer'da tutar; ayrı preflight okuması veya ikinci connection açmaz. Her başlık bloğu en fazla16KiB ve kalan wire sınırı kadardır. Geçerli100/103 gibi informational bloklar ayrı ayrı kontrol edilip özgün byte'larıyla parser'a aktarılır; bunların sayısı/toplamı mevcut wire/deadline sınırından geçer. Informational blokta Content-Length/Transfer-Encoding, duplicate kritik header veya101 protocol upgrade reddedilir. Son HTTP200 bloğundaki kontroller önceki informational blok tarafından kaldırılamaz. Split terminator, partial header ve buffer'dan body aktarımı da tek global deadline/grant expiry ve cleanup sınırındadır; parser'a servis edilen buffer byte'ları yeniden wire sayılmaz.

Compression açma desteği yoktur. Wire sınırı TLS sonrası HTTP response byte'larını (header, framing ve body dahil) sayar; TLS ciphertext/handshake ve DNS paket byte'larını ölçtüğü iddia edilmez. Decoded sınır HTTP framing çıkarılmış identity payload'a ayrıca uygulanır. Content-Length erken sınır kontrolü sağlar; chunked body aynı accumulator sınırından geçer. Sonuç immutable bytes, SHA256 ve wire byte sayısını taşır; HTML/JSON parsing, citation, normalization, retention ve PII politikası sonraki acquisition diliminin işidir.

Statik robots sonucu grant'ın zorunlu alanıdır; robots.txt fetch/evaluation bu teslimde yapılmaz. Gerçek robots/izin/license üretimi, IPv6/compression desteği, server grant deposu, source/budget/job admission bağlama, raw artifact persistence ve canlı source kabulü açık BE-06 işleri olarak kalır. Hiçbir provider/key/source çağrısı veya registry runtime enable bu temel için çalıştırılmaz.

Transport, [HTTP Core public network backend arayüzünü](https://www.encode.io/httpcore/network-backends/) ve [ConnectionPool seçeneklerini](https://www.encode.io/httpcore/connection-pools/) kullanır; [timeout extensions](https://www.encode.io/httpcore/extensions/) kalan süreyle wrapper içinde daraltılır. [HTTPX transport belgeleri](https://www.python-httpx.org/advanced/transports/) üst seviye client transport sınırını tanımlar; burada doğrudan httpcore kullanıldığı için ambient HTTPX client/proxy/cookie durumu taşınmaz. Geliştirme doğrulaması kurulu httpcore1.0.9/httpx0.28.1 public arayüzleri ve gerçek HTTP1 parser üzerinde offline backend ile yapılır. Linux gerçek DNS/TLS/Hetzner/live87 kabulü bu testlerin sonucu değildir.
